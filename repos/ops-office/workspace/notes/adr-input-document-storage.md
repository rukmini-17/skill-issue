# ADR input: where signed HR documents live

Date: 2026-10-16. Stakeholders: Anna Varga (Finance), Tomas Reyes (Operations).

Context: signed offer letters are currently kept on a shared drive with broad access. Retention rules need seven years.

Decision: move signed documents to the access-controlled records archive.

Alternatives:
- Keep the shared drive and tighten folder permissions: rejected because permissions drift and there is no retention control.
- Store them in the HR vendor's portal: rejected because the contract ends in 2027 and export is manual.

Trade-offs: staff need to request access and the migration takes about two weeks.
